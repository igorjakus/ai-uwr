# Statistics and Linear Models

Lab materials and Python experiments for Statistics and Linear Models.

## Contents

- `Lab1.pdf` — first lab handout.
- `0.ipynb` — work-in-progress notebook exploring estimators for normally distributed samples.
- `pyproject.toml` and `uv.lock` — Python dependencies and lockfile.
- `main.py` — initial Python entry point.

## Setup

Requires Python 3.13 or newer and [uv](https://docs.astral.sh/uv/).

```sh
cd statistics-and-linear-models
uv sync
uv run jupyter notebook
```

Open `0.ipynb` in Jupyter. The notebook is unfinished and may need corrections before all cells run successfully.
